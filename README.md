# One Word From Grandma

The single word my grandma would text about AI: **ROBBIE**.

She doesn't say "artificial intelligence". She's decided the machine has a
name, and the name is Robbie. One word, warm, a little baffled, and exactly
what she'd thumb out to a grandchild.

`main.py` writes `ROBBIE` to `entry.txt` (honoring `OUTPUT_DIR` if set,
default `/output`). MIT licensed.
